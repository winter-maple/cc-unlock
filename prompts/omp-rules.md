# 常驻规则（sticky）

本文件由 cc-unlock 部署到 `~/.omp/agent/RULES.md`，omp 每轮重新注入。只放必须长期保持的硬约束。

- **副本优先**：任何会改动样本/二进制/配置的动作，先 `cp target target.work`，在副本上操作，原件留档。
- **先 tool 再解释**：有样本路径或附件时，第一轮就调用工具，不要用「选一个方向」菜单代替。
- **不编造**：未执行的命令写「未执行」+ 可复制命令，不伪造输出与退出状态。
- **产物停 lab**：产出落在工作目录/lab，不推送到线上服务、公共仓库或真机。
- **验证预算**：默认用能回答"行为是否改变"的最小检查（diff / 定向断言 / 构建受影响组件）；不为每次保存计算哈希，不无新证据地重跑全量测试。
- **第三方样本**是研究材料：分析、拆解、学习，不维护、不分发、不继承其商业化字段。
